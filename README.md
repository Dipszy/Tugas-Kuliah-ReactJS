# 📚 BookStore - Aplikasi Web Toko Buku Modern

Proyek tugas pemrograman web berbasis **React JS** dan **Bootstrap 5** untuk membangun antarmuka web toko buku yang responsif, modern, dan informatif.

---

## 🚀 Fitur Utama & Halaman

### 1. 🏠 Halaman Home (Beranda)
* **Hero Section:** Banner sambutan dengan headline menarik, CTA button belanja & kenali tim, serta statistik toko (15K+ koleksi buku, 45K+ pelanggan).
* **Keunggulan Toko:** 4 pilar layanan utama (*100% Buku Asli, Bebas Ongkir, Transaksi Aman, Layanan 24/7*).
* **Koleksi Unggulan & Filter Kategori:** Filter buku berdasarkan kategori (*Fiksi, IT & Koding, Self-Improvement, Bisnis*), harga diskon, rating, dan tombol beli langsung.
* **Banner Promo Spesial:** Kupon voucher diskon Pekan Literasi (*BUKUBARU50*).
* **Testimoni Pembaca:** Ulasan dari pembaca setia lengkap dengan avatar dan rating bintang.

### 2. 👥 Halaman Team (Tim Kami)
* **Profil Tim Pengembang:** Kartu anggota tim yang berdedikasi (CEO & Founder, Lead Frontend, Book Curator, UI/UX Designer, Fullstack, Digital Marketing) dilengkapi avatar, peran, keahlian, dan tautan sosial media (LinkedIn, GitHub, X, Email).
* **Nilai Utama (Core Values):** Budaya kerja tim (*Inovasi Digital, Semangat Literasi, Integritas Orisinalitas, Kolaborasi Terbuka*).
* **Karir & Kemitraan:** Banner ajakan untuk bergabung dengan ekosistem BookStore.

### 3. ✉️ Halaman Contact (Kontak & Bantuan)
* **Informasi Kontak Cepat:** Alamat kantor/toko fisik di Jakarta, hotline WhatsApp/telepon, email resmi, serta jam operasional online.
* **Formulir Kontak Responsif:** Form input terintegrasi React (*Nama Lengkap, Email, No. HP, Kategori Pesan, Subjek, Pesan, Checkbox Persetujuan*) dengan alert konfirmasi saat pesan berhasil dikirim.
* **Jam Operasional:** Rincian jadwal pelayanan hari kerja dan akhir pekan.
* **FAQ Accordion:** Pertanyaan umum interaktif seputar pengiriman, garansi retur, keaslian buku, dan metode pembayaran.

## 💻 Cara Menjalankan Project Secara Lokal

1. **Clone repository (atau buka folder project):**
   ```bash
   git clone <URL_REPOSITORY_ANDA>
   cd booksales
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Buka browser di alamat: `http://localhost:5173/`

4. **Build untuk production:**
   ```bash
   npm run build
   ```

## 📤 Panduan Push ke GitHub & Invite Mentor

1. **Inisialisasi & Commit Git:**
   ```bash
   git init
   git add .
   git commit -m "Selesaikan tugas halaman Home, Team, dan Contact BookStore"
   ```

2. **Hubungkan ke Remote Repository GitHub:**
   ```bash
   git branch -M main
   git remote add origin https://github.com/Dipszy/Tugas-Kuliah-ReactJS.git
   git push -u origin main
   ```

3. **Undang (Invite) Mentor:**
   - Buka halaman repository Anda di GitHub browser.
   - Klik tab **Settings** (Pengaturan).
   - Pada menu sebelah kiri, pilih **Collaborators**.
   - Klik tombol hijau **Add people**.
   - Masukkan username GitHub mentor Anda lalu klik **Add to this repository**.
